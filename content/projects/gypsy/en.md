# Summary

End-to-end digital transformation for an artisan jewelry brand: from manual Instagram management to an autonomous web ecosystem with an editorial catalog and a custom-built inventory admin panel. Real-time stock sync, no developer dependency.

# Gallery

Editorial minimalist design that lets the warmth of bronze, copper, and alpaca metals take center stage — generous whitespace, clean grids, and frictionless mobile filtering. Paired with a private React SPA that turns inventory management into a matter of a few clicks.

# Features

## 01. Real-time synchronization

A direct connection between the React panel, the Node/Express API, and PostgreSQL ensures no customer ever sees a sold-out piece as available. Every status change is reflected instantly on the public catalog.

## 02. Integrated media management

Direct image uploads from the admin panel to Vercel Blob optimize storage without bloating the repository or requiring external pre-editing.

## 03. Efficient hybrid architecture

A clean separation of concerns between a lightweight Vanilla JS public frontend — fast and SEO-friendly — and a powerful React + Vite admin environment.

## 04. Prisma data modeling

A structured schema built for jewelry-specific attributes: materials, collections, availability status, prices, and associated images.
